Industry Problem & Context

The Automotive Sentry Mode Dilemma

Parked vehicle surveillance requires continuous 360° situational awareness, but standard vision models cause severe battery exhaustion.

Parasitic Battery Drain

In standard Sentry mode, running high-resolution neural networks across 4+ surround cameras continuously drains the vehicle's 12V battery and risks stranding the driver.

92% Spatial Redundancy

Surveillance cameras overlooking parking spots observe a stationary environment. Over 90% of the pixel canvas represents unchanging asphalt, parked vehicles, and sky.

ViT Self-Attention Bottleneck

DINOv2 ViT evaluates 2,025 patch tokens per frame regardless of motion, consuming 129.3 ms (74.6% of pipeline latency) calculating redundant static background features.

Alignment with NVIDIA Directives (Pradipt Trivedi, Principal Engineer)

Directive NVIDIA Guidance Engineering Action & Result
1. Native Frame Rate "Consider native 5 FPS vehicle-camera stream as final input." Evaluated directly on incoming 5.0 FPS video streams matching hardware power budgets.
2. Optimization Scope "Focus on Spatial Token Caching; explore intelligent frame skipping." Built GPU patch gating engine (<0.05 ms) forwarding only dynamic tokens + static background bypass.
3. Evaluation Protocol "Benchmark incoming 5 FPS frames directly without modifications as reference." Extracted Golden Record (277 boxes) and proved 96.0% box retention & 0.968 IoU fidelity.
4. Benchmark Dataset "Explore provided dataset list (MEVA/VIRAT/CHAD) or test clips." Benchmarked on DARPA/Kitware VIRAT video, achieving 6.55× speedup and 0.986 IoU.

System Architecture

The UnifiedPerception Perception Stack

A single unified Vision Transformer forward pass extracts visual tokens that feed multi-task downstream heads simultaneously.

Backbone

Shared DINOv2 ViT-S/14

  • 384-dimensional visual embedding
  • 640×640 frame produces 45×45 = 2,025 patches
  • Extracts multi-scale hidden states [3, 6, 9, 12]
  • Single forward pass fuels both detection & action
Spatial Head

Adapter-v2 + YOLO26s

  • Reshapes 1D ViT tokens into 2D feature maps
  • CNN Detail Branch recovers high-frequency edges
  • Native NMS-free end-to-end bounding box regression
  • 43.48 ms latency on RTX PRO 4000 Blackwell
Temporal Head

Kinetics-400 Linear Probe

  • Pools temporal sequence of [CLS] tokens [T, 384]
  • Predicts Top-5 human activities with probabilities
  • Ultra-lightweight: 0.55 ms inference runtime
  • Sliding-window mode for localized event onsets

Algorithmic Innovation

Motion-Aware Token Caching & Patch Gating

How we cut 70.9% of self-attention FLOPs while preserving 98.6% IoU fidelity without retraining weights.

4-Stage Token Caching Diagnostic Strip Frame 22 Case Study
1. Surveillance Feed (5 FPS) Vehicle stationary; pedestrian moving across background.
2. GPU Frame Delta |F_t - F_{t-1}| calculated in <0.05 ms using F.avg_pool2d.
3. 45×45 Patch Mask Dynamic patches forwarded; static background tokens cached (0 FLOPs).
4. YOLO26s Output via Cache Layers [3,6,9,12] refilled from GPU buffer; 98.6% IoU fidelity.

Interactive Telemetry Comparison: Dense Baseline vs. Sparse Caching

Evaluated DINOv2 Tokens / Frame 2,026 590 tokens (-70.9%)
DINOv2 Sparse Forward Latency 129.3 ms 4.99 ms (25.9× faster)
VIRAT Full Video Processing Time 20.23 s 3.09 s (6.55× faster)
Peak GPU VRAM Usage 4,157 MB 2,423 MB (-41.7%)
Why Zero Retraining? Downstream YOLO26s expects a full 45×45 grid. By updating only active patch indices in the GPU feature cache buffer, downstream convolution kernels receive identical geometric representations without ever knowing that 70%+ of tokens were never evaluated!
